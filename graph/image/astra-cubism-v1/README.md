# 씬0 ASTRA Cubism 배포 파일

`01-amr_hgn_design_concept.html`의 우측 로봇에 사용한다. 씬10의 설명 로봇은 별도 기존 자산이다.

- `astra-cubism.js`: 정본 `Live2D/source/waist-v1/astra-cubism.js`의 사본.
- `live2dcubismcore.min.js`: 공식 Cubism 5.3/MOC3 v6 대응 Core. 원본 저작권/라이선스 고지 유지. 출처: https://cubism.live2d.com/sdk-web/core/06/live2dcubismcore.min.js
- `ASTRA-waist-v1.bundle.js`: 실제 MOC3 및 아틀라스의 로컬 묶음. 덱은 USB 로 통째로 옮기므로 Git 으로 추적한다(2026-09-27 사용자 결정 — 종전 Git 제외 · Drive).

갱신/다른 PC 복원: 저장소 루트에서 `node Live2D/preview/deploy-cubism.mjs`. 먼저 Live2D의 런타임 모델/텍스쳐 파일을 복원해야 한다. 다른 PC에서 덱 폴더만 복사할 때는 이 폴더의 세 JS 파일을 모두 포함한다. file:// 직접 열기 지원, 외부 CDN 요청 없음.

2026-09-26 적용: 실제 MOC3 파라미터로 표정·기울기를 구동하고 미소의 붉은 색조는 기본 얼굴 색조로 보정한다. 위쪽 손은 Core 변형 뒤 **손목 중심 국소 회전 약 ±3°를 웹에서 추가**한다. 이 강조 동작은 `.cmo3/.moc3`에 재저장된 키가 아니다.

레이저 앵커는 새 원화 검지 끝의 실측 위치 `(276,548.294)`에 PSD 여백 80px을 더한 `(356,628.294)`이다. 이를 UpperHand의 기본 삼각형에 barycentric 좌표로 부착하고, Core 변형과 추가 손목 회전이 적용된 **실제 렌더 정점**에서 매 프레임 재계산한다. 과거 이미지의 비율 좌표는 사용하지 않는다.

화면 배치: 세로 크기 `min(H*0.98,W*1.25)`, 세로 위치 `H-rdh*0.84`. 아래쪽은 허리 부근에서 프레임 밖으로 잘린다. 재생 시간은 호스트 씬의 시간이며 자체 animationFrame 루프가 없어 일시정지·탐색·배속에 따라간다.

레이저는 콘텐츠 진행률 0.805에서 시작하고 0.925~0.960 구간에서 사라진다. 이전 종료점 0.900보다 현재 씬 기준 약 3.41초 길다. 손끝 잔광은 0.940~0.970에서 소멸한다. 레이저 종료 뒤 2초 동안 양 손목의 동작 속도를 100%→25%로 부드럽게 낮춘다. 감속 곡선을 적분한 시간으로 손 동작을 계산하여 전환 순간 자세가 튀지 않고 역방향 탐색에도 같은 자세가 나온다.

검증: `node Live2D/preview/verify-cubism-deck.mjs`. 7개 장면 시점에서 앵커 위치에 실제 손 픽셀이 존재, 레이저 연장/종료 시각, 종료 후 손 속도 1→0.625→0.25, 전환 연속성과 역방향 탐색, 같은 시간의 자세 고정, 1920×1080·1440×900·1280×720·390×844 렌더, 브라우저 오류 0. 결과: `Live2D/export/waist-v1/deck-qa/`.
